SONHE, DETALHE E REALIZE — POSTGRESQL NO RAILWAY

1. Envie todos os arquivos deste ZIP para a raiz do repositório GitHub do site.
2. Railway > projeto > + New > Database > PostgreSQL. Aguarde ficar Online.
3. Não altere as variáveis do serviço PostgreSQL geradas pelo Railway.
4. No serviço do site (filho/sonhe) > Variables > Raw Editor, configure:
   DATABASE_URL=${{Postgres.DATABASE_URL}}
   ADMIN_USER=admin
   ADMIN_PASSWORD=<senha forte e exclusiva>
   SECRET_KEY=<gere usando python -c "import secrets; print(secrets.token_hex(32))">
   Se o serviço PostgreSQL tiver outro nome, substitua Postgres pelo nome exato.
   Remova apenas as variáveis MYSQLHOST, MYSQLPORT, MYSQLUSER, MYSQLPASSWORD, MYSQLDATABASE antigas do serviço do site.
5. Settings: Root Directory deve ser a pasta que contém app.py.
   Start Command: gunicorn --bind 0.0.0.0:$PORT app:app
6. Faça deploy do PostgreSQL primeiro, depois do site. Acesse /health e /admin.
7. Envie um formulário fictício e confira os registros no painel /admin/painel.
   A tabela orcamentos será criada automaticamente na primeira conexão.

IMPORTANTE: PostgreSQL é um banco novo, dados do MySQL antigo NÃO são transferidos automaticamente.
A área do cliente original autentica somente por WhatsApp e precisa de autenticação mais forte antes de expor dados reais.
Não publique credenciais no GitHub. Troque as senhas anteriormente expostas.
O vídeo da atualização anterior está integrado; coloque o arquivo em static/videos/video.mp4.
